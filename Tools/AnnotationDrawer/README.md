# Annotation Drawer

Инструмент для визуализации bounding box разметки на изображениях.

## Использование

1. **Положите изображение** в папку `input/`
   - Поддерживаемые форматы: `.jpg`, `.jpeg`, `.png`, `.bmp`

2. **Положите файл разметки** в папку `input/`
   - Формат: текстовый файл `.txt`
   - Если имя файла совпадает с изображением (например, `frame_00000.jpeg` и `frame_00000.txt`), они будут автоматически сопоставлены

3. **Запустите скрипт**:
   - Двойной клик на `RUN.bat`
   - Или в PowerShell: `.\draw_annotations.ps1`

4. **Результат** появится в папке `output/`

## Формат разметки

Каждая строка файла разметки:
```
Label, Label, MinX, MinY, MaxX, MaxY
```

Пример:
```
M1A1_D, M1A1_D, 799, 462, 1039, 564
T72B, T72B, 10, 384, 194, 437
BUK_M1_D, BUK_M1_D, 18, 270, 72, 296
```

## Цветовая схема

| Класс | Цвет |
|-------|------|
| M1A1 / M1A1_D | Красный |
| M1133 / M1133_D | Оранжевый |
| T72B / T72B_D | Зелёный |
| M270 / M270_D | Синий |
| BUK_M1 / BUK_M1_D | Фиолетовый |
| BMP3 / BMP3_D | Жёлтый |
| M109 / M109_D | Голубой |
| Другие | Белый |

## Добавление новых классов

Откройте `draw_annotations.ps1` и добавьте новый класс в `$colorMap`:
```powershell
$colorMap = @{
    "NewClass" = "YourColor"
    ...
}
```
